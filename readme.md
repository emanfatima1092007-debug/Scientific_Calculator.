# 🌸 Premium Scientific Calculator

A modern scientific calculator built using **HTML**, **CSS**, and **JavaScript** with a beautiful glassmorphism UI, smooth animations, dark mode, calculation history, and basic scientific operations.

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📐 Square Root (√)
- 🔲 Square (x²)
- 🧊 Cube (x³)
- 📊 Sine (sin)
- 📊 Cosine (cos)
- 📊 Tangent (tan)
- 🕒 Calculation History
- 🌙 Dark / Light Mode
- 📋 Copy Result
- ⌨️ Keyboard Support
- 🔊 Button Click Sound
- 💎 Glassmorphism Design
- 📱 Responsive Layout

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start calculating!
